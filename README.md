# Una — голосовой помощник для Android

**Una** (произносится «Юна») — локальный голосовой ассистент для телефона: слушает имя, понимает
команды, звонит, управляет музыкой и громкостью, ставит напоминания и будильники, ведёт заметки.
Работает **офлайн**: распознавание речи идёт на устройстве, звук никуда не отправляется.

Проект вырос из открытого ассистента [Dicio](https://github.com/Stypox/dicio-android) (GPL-3.0):
взяты движок навыков, интерфейс и офлайн-распознавание Vosk. Всё остальное — своё.

---

## Что умеет

### Голос и понимание
- **Слово-триггер «Юна»** — офлайн, на Vosk с ограниченной грамматикой.
- **Точное распознавание команды** — GigaAM v3 (216 МБ, на устройстве, MIT), с пунктуацией и числами.
- **Защита от ложных срабатываний**: имя должно быть первым словом с уверенностью ≥ 0.85, плюс
  строгая перепроверка через GigaAM (отключается в настройках).
- Команда произносится **одной фразой**: «Юна, следующий трек».

### Действия
| Что | Пример |
|---|---|
| Музыка | «следующий трек», «пауза», «продолжи», «переключи», «дальше» |
| Громкость | «громкость на 7», «громче», «тише» (понимает и цифры, и слова) |
| Звонки | «позвони Юле», «позвони на номер 8 999 …» |
| СМС | «отправь смс Юле: я задержусь» |
| Календарь | «запиши в календарь завтра в 15:00 врач» |
| Заметки | «запиши в заметки купить хлеб», «что в заметках», «удали заметку про хлеб» |
| Напоминания | «напомни в 18:30 позвонить маме», «через 10 минут», «завтра в 9» |
| Будильник и таймер | «будильник на 7», «таймер на 5 минут» |
| Медиа-инфо | «что играет?» |
| Система | «заряд?», «беззвучный режим», «вибрация», «со звуком» |
| YouTube | «включи на Ютубе котиков» |
| Яндекс Музыка | «включи мою волну», «включи мне нравится» |
| Из Dicio | время, калькулятор, таймер, фонарик, поиск, навигация, открытие приложений |

Навыки Dicio, которые не работают по-русски или требовали чужих ключей (шутки, перевод,
уведомления, погода), выключены по умолчанию — их можно включить в настройках навыков.

### Что вырезано из форка

Приложение выросло из Dicio, но не тащит его наследство: доступен только русский язык, команды
распознаёт GigaAM и в приложении, и в фоне (Vosk остался только сторожем слова-триггера), убраны
выбор чужих языков, импорт моделей пробуждения OpenWakeWord, ссылки на инфраструктуру Dicio и
42 неподдерживаемых перевода.

### Инфраструктура
- **Самообновление**: приложение проверяет сервер каждые 30 минут, скачивает APK, сверяет
  SHA-256 и предлагает установку (Android всегда спрашивает подтверждение).
- **Разрешения на виду**: экран «Разрешения» показывает каждое право, его состояние и кнопку
  выдачи, включая СМС и календарь.
- **Журнал «Что я услышала»** — последние фразы, счётчики триггеров, статус модели.
- **Сервер** (опционально): словарь команд, память, приём журнала и аудио ложных срабатываний.
- **Согласие на отправку данных** — отдельный экран, по умолчанию выключено.
- **Свой токен на устройство** — регистрация при первом запуске, данные привязаны к телефону.

## Установка

1. Скачать APK (страница раздачи проекта или сервер).
2. Разрешить установку из этого источника; при предупреждении Play Protect — «Всё равно установить».
3. При первом запуске выбрать **русский язык**.
4. Разрешить микрофон, уведомления и исключить приложение из экономии батареи
   (на Infinix/XOS дополнительно включить «Автозапуск»).
5. Включить слово-триггер в настройках — приложение скачает модель (~45 МБ).
6. Открыть «Что я услышала» → «Скачать» модель распознавания (~216 МБ).

Требования: Android 5.0+ (arm64 или armeabi-v7a), ~300 МБ свободного места, микрофон.

## Как это работает

```
Микрофон
   │
   ├─ Vosk (45 МБ, грамматика) — постоянно слушает только «юна»
   │        │ сработал триггер
   │        ▼
   ├─ строгая проверка: последние 2.2 с прогоняются через GigaAM
   │        │ подтверждено
   │        ▼
   └─ GigaAM (216 МБ, on-device) — распознаёт команду целиком
            │
            ▼
      быстрые команды (стемы слов) → навыки Dicio → ответ уведомлением
```

Словарь команд и порог триггера приходят с сервера (`/config`) и кэшируются — правки фраз не
требуют пересборки приложения.

---

## Приватность

- Звук обрабатывается **на телефоне**, никуда не отправляется и не сохраняется.
- Журнал распознавания хранится на устройстве.
- Отправка на сервер (журнал + короткие записи ложных срабатываний) — **только с согласия**,
  отключается в любой момент.
- Пароли и ключи не собираются.

## Сборка

```bash
# JDK 21 (или Android Studio JBR) + Android SDK 36
./gradlew :app:assembleDebug
```

Локальная библиотека распознавания лежит в `app/libs/sherpa-onnx.aar` (47 МБ, Apache-2.0).

---

## Сервер (опционально)

Небольшой FastAPI-backend (`server/`): словарь команд, память, журнал, приём аудио, раздача
обновлений. Нужен только для синхронизации и обновлений; приложение работает и без него.
