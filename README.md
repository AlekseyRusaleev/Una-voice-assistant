# Una — голосовой помощник для Android

Una (произносится «Юна») — ассистент для телефона, который слышит своё имя и выполняет команды.
Распознавание речи идёт на устройстве: разговор никуда не отправляется, интернет нужен только для
обновлений и для команд вроде поиска или YouTube.

Проект вырос из открытого ассистента [Dicio](https://github.com/Stypox/dicio-android) (Stypox и
участники, GPL-3.0): оттуда взяты движок навыков, интерфейс и часть инфраструктуры. Всё, что связано
с русским языком, триггером и моделями, — своё.

## Что умеет

| | Пример |
|---|---|
| Музыка | «следующий трек», «пауза», «громче» |
| Громкость | «громкость на 7», «тише» |
| Звонки | «позвони Юле», «позвони на номер 8 999 …» |
| СМС | «отправь смс Юле: я задержусь» |
| Календарь | «запиши в календарь завтра в 15:00 врач» |
| Заметки | «запиши в заметки купить хлеб», «что в заметках» |
| Напоминания | «напомни в 18:30 позвонить маме», «через 10 минут» |
| Будильник, таймер | «будильник на 7», «таймер на 5 минут» |
| Система | «заряд?», «беззвучный режим», «включи фонарик» |
| Ещё | YouTube, Яндекс Музыка, время, калькулятор, поиск, навигация, запуск приложений |

Команду можно говорить одной фразой сразу после имени: «Юна, следующий трек».

## Установка

1. Поставить APK и разрешить установку из этого источника.
2. Выдать разрешения — приложение спросит их при первом запуске.
3. Дождаться загрузки моделей: 45 МБ для слова-триггера и 216 МБ для распознавания команд.
4. На Infinix/XOS дополнительно включить автозапуск и снять ограничения батареи.

Нужен Android 5.0+ (arm64 или armeabi-v7a) и около 300 МБ свободного места.

## Как это работает

```
микрофон
   │
   ├─ Vosk: слушает только «Юна» (45 МБ, грамматика из имени и слов команд)
   │      │ сработало
   │      ▼
   ├─ перепроверка последних 2 секунд через GigaAM (отсекает ложные срабатывания)
   │      │ подтверждено
   │      ▼
   └─ GigaAM: распознаёт команду целиком (216 МБ, на устройстве)
          │
          ▼
     быстрые команды → навыки → ответ уведомлением
```

Словарь команд приходит с сервера и кэшируется, так что фразы можно править без пересборки.

## Приватность

- Звук обрабатывается на телефоне.
- Заметки, СМС и события календаря на сервер не уходят.
- Журнал распознавания (услышанные фразы и короткие аудиофрагменты) отправляется на сервер
  по умолчанию — это нужно, чтобы улучшать модель. Отключается в «Что я услышала» или кнопкой
  при первом запуске.
- Подробности — в [PRIVACY.md](PRIVACY.md).

## Сборка

```bash
# нужен JDK 21 (или JBR из Android Studio) и Android SDK 36
./gradlew :app:assembleDebug
```

Библиотека распознавания лежит в `app/libs/sherpa-onnx.aar` (47 МБ, Apache-2.0).

## Сервер

Небольшой FastAPI-backend в `server/`: словарь команд, приём журнала и аудио, раздача обновлений.
Приложение работает и без него, но тогда нет автообновления.
